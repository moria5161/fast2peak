# IR denoising benchmark

The final IR benchmark compares RAW, SavGol, a trained autoencoder and pretrained Fast2PeakRPE (F2P). This subproject saves numerical metrics only.

## Structure

```text
IR/
├── configs/       # YAML experiment configuration
├── models/        # Dense autoencoder and shared F2P model adapter
├── datasets/      # Packed ATR data and paired data (Git-ignored)
├── training/      # Optimization, validation selection and checkpoint saving
├── inference/     # F2P inference, evaluation and public metric export
├── utils/         # Configuration, loaders, preprocessing, metrics, upstream utilities
├── scripts/       # Local Shell/Slurm helpers (Git-ignored)
├── docs/          # Public data description and final numerical results
├── outputs/       # Checkpoints, predictions, histories and metrics (Git-ignored)
├── main.py        # Unified entry point
└── requirements.txt
```

## Run

From the repository root, activate the `fast2peak` environment:

```bash
conda activate fast2peak
python otherbench/IR/main.py prepare
python otherbench/IR/main.py train --device cuda
python otherbench/IR/main.py evaluate --device cuda
python otherbench/IR/main.py export
```

Settings are in [configs/benchmark.yaml](configs/benchmark.yaml). Paths in YAML are relative to `otherbench/IR`, regardless of the working directory. Choose another configuration with `--config PATH`; command-line options override YAML settings. For example: `python otherbench/IR/main.py train --epochs 100 --device cuda`.

The local `datasets/` directory contains `atr_spectra.npy` and `paired/`. Preparation reuses frozen `selected_clean.npy`, `wavenumbers.npy`, `manifest.json` and `split.csv` in `datasets/paired/` to reproduce the original selection/order. Supply these data assets separately when distributing a checkout, since `datasets/` is Git-ignored. F2P inference requires the pretrained checkpoint and its adjacent `config.yaml`; their path is configurable. Autoencoder weights can be regenerated by training.

See [the workflow](docs/workflow.md) for data, protocol, artifact locations and local Slurm commands. [The data description](docs/data_README.md) contains all 174 column labels and the original source statement.

## Final results

| Method | Pearson mean ↑ | Pearson median ↑ | RMSE ↓ | SNR (dB) ↑ |
|---|---:|---:|---:|---:|
| RAW | 0.8503 | 0.8726 | 0.0748 | 5.57 |
| SavGol | 0.9143 | 0.9316 | 0.0457 | 10.04 |
| Autoencoder | 0.9444 | 0.9462 | 0.0408 | 11.55 |
| F2P | **0.9849** | **0.9869** | **0.0217** | **16.38** |

All metrics use the same 4,000 held-out test pairs. RMSE and SNR are means of per-spectrum metrics. The F2P row uses amplitude-corrected outputs; uncorrected outputs round to the same displayed values. Public numerical snapshots are [docs/leaderboard.csv](docs/leaderboard.csv) and [docs/evaluation_summary.json](docs/evaluation_summary.json).

The original ATR data source/permission statement and reference citation are retained in `docs/data_README.md`. Upstream code in `utils/upstream/` retains its author copyright and GPL notices.
